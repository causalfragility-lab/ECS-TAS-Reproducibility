# ECS-TAS-Reproducibility

Reproducibility materials for:

**Evidence, Calibration, and Stability: A Reporting Architecture for Statistical Practice Under Model Uncertainty**

## Files

- `ECS_TAS_Reproducibility_R` — Base-R code reproducing the numerical analyses and figures.
- `ECS_diabetes_data.csv` — empirical 442-observation dataset used in the specification analysis.

## Reproduction

Place both files in the same folder and run `ECS_TAS_Reproducibility_R` in R.

The script reproduces the numerical results reported in the manuscript and generates the corresponding figures.
